# CDA3103-Project
Core part of a mini processor simulator using the C programming language. It demonstrate functions of the MIPS processor as well as the principle actions of the datapath and the control signals of a MIPS processor.
I built in C for CDA 3103: Computer Logic and Organization at UCF.

The project simulates a single-cycle MIPS processor, including:

Instruction fetching and decoding
Registers and memory
ALU operations
Control signals
Program counter updates
MIPS instruction execution
Running

Compile with:

gcc -o spimcore spimcore.c project.c

Then run:

./spimcore <filename>.asc
